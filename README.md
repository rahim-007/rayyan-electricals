# Rayyan Electrical Enterprises

Industrial Electrical Solutions and Engineering Services web platform.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/rahim-007/rayyan-electricals)

## ⚡ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Vanilla CSS (Fluid clamp responsive design)
- **Animations**: GSAP + ScrollTrigger + Lenis Smooth Scroll
- **Hosting**: Render Static Site (Free Tier)

## 🚀 Local Development
`ash
npm install
npm run dev
`

## 📦 Production Build
`ash
npm run build
`
